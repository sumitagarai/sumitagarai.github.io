# sumitagarai.github.io

Personal site for Sumita Garai. Static HTML/CSS; no build step required.

## Local preview
Open `index.html` directly in your browser, or use a simple server:

```bash
python3 -m http.server 4000
# then visit http://localhost:4000
```

## Deploy
Commit to the `main` branch of this repository configured for GitHub Pages.
